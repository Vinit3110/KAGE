# Locally served fonts

Downloaded from the Google Fonts CSS API and its `fonts.gstatic.com` asset URLs.

| Family | Files | License |
| --- | --- | --- |
| Cormorant Garamond | `cormorant-garamond-500.ttf`, `cormorant-garamond-700.ttf` | `Cormorant-OFL.txt` |
| Inter | `inter-400.ttf`, `inter-600.ttf` | `Inter-OFL.txt` |
| IBM Plex Mono | `ibm-plex-mono-400.ttf` | `IBMPlexMono-OFL.txt` |

The CSS API request selected normal styles and `display=swap`. No external font request is needed when viewing the site.

Official license sources:

- https://github.com/google/fonts/blob/main/ofl/cormorantgaramond/OFL.txt
- https://github.com/google/fonts/blob/main/ofl/inter/OFL.txt
- https://github.com/google/fonts/blob/main/ofl/ibmplexmono/OFL.txt

Japanese decorative characters use locally available Japanese serif fonts, with a serif fallback. The verified character in the mark/seal is 影 (shadow); 影の道 is the shadow path, and 学び続ける means to continue learning.
